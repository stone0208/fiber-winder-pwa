# 配布時メモ

## 配布時に添える説明文例

このツールは、ファイバ巻取り条件から必要rpmまたはファイバ径を計算するローカルWebアプリです。

- HTML+JavaScriptで動作します。
- 外部サーバ通信は使用していません。
- 入力条件はブラウザ内保存（localStorage）です。
- CSV保存はブラウザのダウンロード機能を使用します。
- 計算値は理論値です。実条件は温度、張力、滑り等で変動するため、最終条件は実機で確認してください。

## 配布時の推奨
- ZIPのまま共有する
- 版番号を変えずに中身だけ差し替えない
- 修正版を出す場合は v1.0.1、v1.1.0 のように版を上げる
- 問い合わせ時は、使用している版番号を確認する
