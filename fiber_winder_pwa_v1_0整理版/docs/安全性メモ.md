# 安全性メモ

## 構成
本ツールは以下のみで構成されています。

- HTML
- CSS
- JavaScript
- SVG
- PWA用 manifest
- service worker

## 通信
外部サーバへデータ送信する処理は想定していません。

確認時は、コード中に以下のような外部通信処理がないかを見るとよいです。

- `fetch(`
- `XMLHttpRequest`
- `WebSocket`
- 外部URLの `<script src="https://...">`
- 外部URLの `<link href="https://...">`

## 保存
保存はブラウザ内の localStorage を使用します。
ブラウザデータを消去すると保存条件も消える可能性があります。

## CSV
CSV保存はブラウザの標準ダウンロード機能を使用します。
保存先はブラウザ設定に依存します。
CSV読込はユーザーが選択したCSVのみを読み込みます。
