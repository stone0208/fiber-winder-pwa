# ファイバ巻取り計算 PWA

## 概要
ファイバ巻取り条件から、必要な巻取りローラ回転数または生成されるファイバ径を計算するローカルWebアプリです。

## 主な機能
- 径 → rpm 計算
- rpm → 径 逆算
- 4条件タブによる比較
- 保存済み条件の管理
- CSV保存・CSV読込
- Undo
- PWA対応
- オフライン動作
- ブラウザ内保存（localStorage）

## 配布・起動方法
1. このフォルダ一式を任意の場所に置く
2. `index.html` をブラウザで開く
3. PWAとして使う場合は、必要に応じてローカルサーバーや社内Webサーバー上で開き、ブラウザからインストールする

## 注意
- 本ツールは理論計算用です。
- 体積保存、真円断面、滑りなしを前提にしています。
- 実際のファイバ径は温度、張力、滑り、材料状態などで変動します。
- 最終条件は実機確認を優先してください。

## 安全性メモ
- 外部サーバ通信は使用していません。
- 保存はブラウザ内の localStorage を使用しています。
- CSV保存はブラウザのダウンロード機能を使用します。
- HTML / CSS / JavaScript / SVG のみで構成されています。
- 必要に応じて生成AIや社内レビューでコード内容を確認できます。
